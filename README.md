## Что дальше

1. Склонировать репозиторий:
   ```bash
   git clone https://github.com/<ваш-логин>/apps.git
   cd apps
   ```
2. Создать первую ветку под задачу:
   ```bash
   git checkout -b feature/first-change
   ```
3. Закоммитить изменения и отправить на GitHub:
   ```bash
   git add .
   git commit -m "Первое изменение"
   git push -u origin feature/first-change
   ```
