# ДМБ Таймер

Дембельский таймер с точностью до секунды. Устанавливается на телефон как обычное приложение (PWA) и работает офлайн.

**Живая версия:** https://dmb-timer-markusfarfall.vercel.app

## Что умеет

| Раздел | Содержимое |
|---|---|
| **Таймер** | обратный отсчёт до дембеля до секунды, выбор режима «служу» / «жду», табло (Board) для показа на экране |
| **Стата** | проценты, часы, оставшееся время, прогресс по этапам службы |
| **Календарь** | разбивка срока по месяцам и дням, отметки и заметки по дням |
| **Сантиметр** | «сантиметр» дембеля — визуальная шкала срока |
| **Медали** | достижения: «Первый шаг», «Первые сутки», «Экватор», «100 дней в строю», «Миллион секунд» и другие |

Дополнительно: онбординг при первом запуске, профиль (дата начала и конца службы, имя), 6 тем оформления
(Хаки, ВДВ, Флот, Погранцы, Ночной наряд, ВКС), режим табло, «поделиться» итогом, настройки (миллисекунды, единицы, виброотклик).
Есть цитаты и распорядок дня — меняются в зависимости от режима и времени суток.

## Стек

- **Vite 7** + **React 19** + **TypeScript 5.9**
- **Tailwind CSS 4** через `@tailwindcss/vite`
- `vite-plugin-singlefile` — вся сборка инлайнится в один `dist/index.html`
- `canvas-confetti` (салют по достижениям), `lucide-react` (иконки), `clsx` + `tailwind-merge`

## Разработка

```bash
npm ci          # установка зависимостей
npm run dev     # локальный сервер разработки
npm run build   # прод-сборка в dist/
npm run preview # посмотреть собранную версию
```

## Устройство

```
src/
  main.tsx            точка входа
  App.tsx             каркас: вкладки, тема, тосты, модальные окна
  components/         экраны приложения (Home, Stats, CalendarView, Tape, Medals,
                      Board, Onboarding, ProfileForm, Settings, ShareSheet, ui)
  lib/
    data.ts           звания, темы, цитаты, распорядок, достижения
    time.ts           расчёты сроков службы
    hooks.ts          useStored (localStorage), useNow, useRafNow
    pwa.ts            регистрация service worker, установка на домашний экран
    share.ts          «поделиться»
    format.ts         форматирование чисел и дат
    types.ts          типы
public/
  manifest.webmanifest  манифест PWA (ru, standalone, portrait)
  sw.js                 офлайн-кэш: core-файлы + догрузка по сети
  icon.svg              иконка
```

Данные пользователя хранятся только в `localStorage` браузера (`dmb.profile`, `dmb.prefs`, `dmb.notes`,
`dmb.seenMedals`) — сервера и аккаунтов нет, ничего никуда не отправляется.

## Деплой

Проект живёт в монорепозитории [`MarkusFarfall/apps`](https://github.com/MarkusFarfall/apps) в папке `projects/dmb-timer`
и разворачивается отдельным проектом на Vercel: **Root Directory** = `projects/dmb-timer`, фреймворк — Vite.
Каждый push в `main`, затрагивающий эту папку, обновляет прод автоматически.
