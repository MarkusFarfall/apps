# Атмосфера — время суток, сезоны, погода

Самостоятельный модуль на чистом TypeScript: без React, без DOM, без зависимостей.
Считает **состояние мира**, а рисует его кто угодно — сцена входа, игровая сцена, карта.

```
atmosphere/
├── index.ts     класс Atmosphere, адаптер старой игры, сводка для UI
├── types.ts     Season / WeatherId / Climate — те же, что в src/game/types.ts
├── astro.ts     высота/азимут солнца и луны, долгота дня, фаза луны
├── weather.ts   12 видов погоды, марковская цепь по сезонам и климату, температура
└── palette.ts   палитра неба, моря и суши по высоте солнца + погода + сезон + климат
```

## Что умеет

| Слой | Детали |
| --- | --- |
| **Время** | реальная астрономия для широты (по умолчанию 58°): летом белые ночи, зимой короткий день; солнце и луна идут по траекториям |
| **Луна** | настоящая фаза по дате, видимый серп/диск, лунный свет подсвечивает ночную палитру |
| **Сезоны** | индекс 0..3 как в игре; влияют на долготу дня, температуру, цвет моря, растительность, снег на берегу, листопад, цветение |
| **Погода** | 12 видов: ясно, малооблачно, облачно, пасмурно, туман, морось, дождь, ливень, гроза, шторм, снег, метель |
| **Осадки** | вид осадков решает температура: при −1…+2 °C дождь превращается в мокрый снег, ниже — в снег |
| **Явления** | молнии (событие с расстоянием → задержка грома), радуга после дождя напротив солнца, полярное сияние в ясные ночи с осени по весну, льдины при морозе, снежный покров копится и тает |
| **Ветер** | скорость с порывами, плавно меняющееся направление |
| **Свет** | `daylight`, `night`, `golden`, `lights` (пора зажигать маяк и окна), видимость солнца/луны/звёзд с учётом облаков и тумана |

## Подключение к «Знакомой воде»

```ts
import { Atmosphere } from './atmosphere';
import { WEATHER_INFO, DAYS_PER_SEASON } from './world';

const atm = new Atmosphere({ climate: loc.climate });

// в игровом цикле
atm.syncFromGame({
  minute: state.minute,   // минута суток 0..1439
  day: state.day,         // номер игрового дня
  season: state.season,   // 0..3
  weather: state.weather, // 'clear' | 'cloudy' | 'rain' | 'storm' | 'fog' | 'snow'
  climate: loc.climate,
  daysPerSeason: DAYS_PER_SEASON,
});
atm.update(dt);

const A = atm.state;
// A.palette.skyTop / seaNear / …, A.sunElev, A.sunAz, A.moonPhase,
// A.rain, A.snow, A.fog, A.wind, A.cover, A.lights, A.rainbow, A.aurora …

// обратно в игровую логику (клёв, волны): по-прежнему 6 состояний
WEATHER_INFO[atm.weatherId];
atm.onLightning(({ dist, power }) => audio.thunder(0.3 + dist * 4.5, power));
```

`syncFromGame` можно вызывать каждый кадр: при смене `weather` атмосфера плавно (≈4 с)
перетекает к новому состоянию и раскладывает `WeatherId` на оттенок
(`rain` → морось / дождь / ливень, `storm` → гроза / шторм, зимой — метель),
выбор оттенка детерминирован по дню, поэтому не мигает.

Названия полей `state.minute` / `state.day` — условные: подставьте те, что в `persist.ts`.

## Автономный режим

Без `syncFromGame` атмосфера сама ведёт часы (`timeScale`, 1 — реальное время) и погоду
(марковская цепь в ускоренном «погодном» времени `weatherScale`, чтобы сцена жила).
Ручное управление: `setHour`, `setSeason`, `setWeather(kind | 'auto')`, `setTimeScale`,
`setClimate`, `resetToNow`. Для UI — `summary()` со строками на русском.
