# События — живое море

Модуль случайных событий на чистом TypeScript (без React и DOM). Заменяет старый каталог из `world.ts`; в игре используется один `EventDirector`. Поля `events` и `nextEventAt` в сохранении оставлены только для совместимости. Сохранения EventDirector v1 мигрируют в v2 внутри прежнего JSON-поля, без изменения схемы БД.

```
events/
├── types.ts      EventDef, LiveEvent, эффекты, выборы, сохранение
├── catalog.ts    основные события и подписи эффектов
├── gameCatalog.ts основной список игры и сохранённые дополнительные явления
├── director.ts   EventDirector — планирование, цепочки, выборы, баффы, save/load
└── index.ts      экспорт + ctxFromAtmosphere()
```

## Что изменилось по сравнению с оригиналом

| Было | Стало |
| --- | --- |
| ~8 событий, `requires(ctx) → boolean` | 50 событий, `when(ctx) → вес`: 0 — нельзя, >1 — особенно вероятно |
| условия: ночь / локация / погода | время, высота солнца, сезон, климат, 12 видов погоды, температура, ветер, туман, облачность, фаза луны, звёзды, сияние, влажность после дождя, глубина, история событий |
| случайный бросок по таймеру | «режиссёр»: обычный интервал 520–1160 игровых минут (~19–43 реальных минуты), после крупного — дополнительное затишье; ротация категорий и защита редких явлений от «засухи» |
| событие просто «идёт» | предвестие → нарастание → пик → спад; эффекты масштабируются по интенсивности |
| нет связи между событиями | цепочки: чайки → косяк → дельфины/косатки, буревестники → шквал → волна-убийца → обломки, туман → корабль-призрак, звездопад → упавшая звезда, кит → песнь кита, бутылка → карта → тайник, сигнал бедствия → благодарность |
| только множители клёва | клёв, редкие, легенды, цены, опыт, риск снастей, удача + добавки к погоде (шквал усиливает ветер, стена тумана — туман, пляска сияния — сияние, ледоход — льдины) |
| — | события с выбором (бутылка, обломки, сеть-призрак, соперник, лавка, сигнал бедствия, упавшая звезда, тайник) с наградами и временными эффектами |
| журнал и каталог всех событий | явления показываются только при встрече; полный список и история открытий в интерфейсе не раскрываются |

## Категории

**Рыба** — косяк, чайки, шар сардины, котёл тунца, холодное течение, нерест сельди, ход лосося, кальмары на свет, ход угря, нерест кораллов, летучие рыбы.
**Обитатели** — дельфины, кит, песнь кита, косатки, акулы, тюлени, черепаха, медузы, светящийся планктон, буревестники.
**Небо** — звездопад, пляска сияния, гало, зелёный луч, лунная радуга, солнечное затмение, фата-моргана.
**Тайны** — корабль-призрак, голоса над водой, огни в глубине, упавшая звезда, тень под килем.
**Стихия** — шквал, волна-убийца, водяной смерч, огни святого Эльма, стена тумана, маяк погас, град, ледоход, красный прилив.
**Находки** — письмо в бутылке, обломки, тайник по карте, брошенная сеть.
**Люди** — соперник, плавучая лавка, сигнал бедствия, благодарность спасённых, праздник в посёлке, регата.

## Подключение к «Знакомой воде»

```ts
import { EventDirector, ctxFromAtmosphere } from './events';

const director = new EventDirector({ seed: save.seed });
director.fromLegacy(save.events, save.nextEventAt, save.minutes); // старое сохранение
// или director.load(save.director) — новое

// игровой цикл (T — абсолютные игровые минуты, как SaveData.minutes)
director.update(save.minutes, ctxFromAtmosphere(atm, { loc: save.location, deep: LOC_BY_ID[save.location].maxDepth > 100 }));
atm.mods = director.atmoMods();

// механика: вместо перемножения EVENTS[...].bite
const m = director.multipliers(); // { bite, rare, legendary, price, xp, gearRisk, luck }

// события → лог/баннер/звук; награды применяет игра
director.on((msg) => {
  if (msg.type === 'outcome' && msg.outcome.reward) applyReward(msg.outcome.reward);
});

// выбор игрока в событии-находке
director.choose(uid, 'open');

// сохранение
save.director = director.save();
Object.assign(save, director.toLegacy()); // events + nextEventAt для старого кода
```

Id старых событий (`shoal`, `gulls`, `plankton`, `whale`, `ghost_ship`, `meteor`, `current`) сохранены,
так что `fromLegacy` подхватит события из существующих сохранений.

## Визуал и звук

Сцена рисует события через `components/game/scene/eventFx.ts`: у каждого события есть список `fx`
(40 эффектов: кит с фонтаном, дельфины, косатки, плавники, корабль-призрак, затмение, гало, зелёный луч,
смерч, салют, ракета бедствия, бутылка на волнах…). Волну-убийцу и погасший маяк обрабатывает сам движок.
Звуки — `authAudio.cue()` (начало, предвестие, открытие, исход) и фоновые петли `events(ids)`.
