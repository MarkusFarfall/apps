Как это устроено

  • Исходники проекта лежат в папке projects/<имя> этого репозитория.
  • На Vercel каждому проекту соответствует отдельная запись с Root Directory на его папку — сборки не мешают друг другу.
  • Ветка main деплоится в прод, остальные ветки дают preview-ссылки.
  • Этот каталог — статический site/index.html, он же корневой домен.
